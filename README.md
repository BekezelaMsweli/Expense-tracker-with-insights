# 💰 Personal Expense Dashboard

A Streamlit dashboard that analyzes income, expenses, and savings to understand personal financial habits.

---

## 📊 Features
- Monthly income vs expenses tracking  
- Savings calculation  
- Spending breakdown by category  
- Pie, line, and bar charts  
- Key financial insights  

---

## 🛠️ Tech Stack
Python • Pandas • Matplotlib • Streamlit  

---

## 📁 Files
- Dashboard expenses.py  
- Expenses.csv  
- requirements.txt  

---

## ▶️ Run Project
```bash
pip install -r requirements.txt
streamlit run "Dashboard expenses.py"
